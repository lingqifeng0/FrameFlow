# V26 视频亮度、夜间护眼与拉伸验证

日期：2026-10-15。公开版本 V26，EXE 文件版本 `7.1.2.1026`。

## 新增行为

- “设置 → 常规 → 画面调节”与右键精简面板共用同一套状态。亮度范围 −100～100，0 为原始亮度；夜间护眼默认关闭，暖色强度默认 35%，范围 0～100%，每级 5%。
- 亮度、夜间开关、暖色强度分别保存；关闭夜间模式保留强度，恢复原色。单独恢复亮度、单独恢复强度与“恢复所有设置默认值”均已接入。
- 原有 `mpv.conf` 亮度在首次升级时读入新界面；此后普通亮度快捷键、原有增减亮度按钮也会同步到新界面并保存。
- 右键增加调节入口与夜间开关；可编辑工具栏增加两个可选动作，默认仍是 6 个自定义按钮、上限 16 个槽位。常用快捷键由 24 项变为 26 项，新增动作初始没有分配按键。
- 精简面板再次点击按钮收起；关闭后释放 WPF 视图、事件订阅与宿主。设置搜索可定位“亮度”“夜间护眼”等词。

## 渲染与保存

亮度使用 mpv 原生 `brightness` 属性。暖色通过 `OUTPUT` 阶段的 GPU 着色器降低绿色、蓝色通道的增益，35% 时目标增益为 R=1、G=0.93、B=0.8075。它不修改源文件，也不改变操作系统或显示器设置。

采用兼容默认 `vo=gpu` 的 20 个可复用强度文件。只保留一个本功能的活动着色器，并保留用户原有着色器的路径与顺序；使用原生 node 数组原子更新列表，避免先移除再添加产生无暖色的中间帧。拖动期间按 100 ms 合并到最新强度，停下 300 ms 后保存；松开、收起或关闭时提交最终值。0% 与关闭均移除效果。

没有增加 CPU 视频滤镜或全窗口半透明覆盖层。拉伸预览继续使用原有已渲染的 `window` 帧，包含亮度与暖色；原有 GPU 窗口冻结、最终尺寸确认与圆角处理保持。

着色器语法与列表操作依据 [mpv 官方手册](https://mpv.io/manual/stable/#options-glsl-shaders)。默认 `gpu` 与 `gpu-next` 支持用户着色器；手册的可调 `glsl-shader-opts` 参数限定 `gpu-next`，因此没有为此功能切换默认视频输出。
