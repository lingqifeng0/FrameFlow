# V16 顶部工具栏与声音增强验证

日期：2026-10-11。版本为 `7.1.2-modern.16`。

本次按用户指定将顶部工具栏背景改成 `#115FFF`，文字和图标使用白色。圆角只应用于蓝色工具栏自身的四个角，半径为 6 个逻辑像素，按 DPI 缩放。`RoundedPanel` 根据工具栏尺寸更新自身裁剪区域，包含其中的子控件；播放器外框、底部控制条和八个窗口拉伸区域继续使用原来的形状。顶部按钮两端留有边距，避免圆角裁剪触及图标。

音量面板新增清晰标注的“声音增强”开关与说明。沿用原来的 `VolumeBoost` 保存字段，开启后只扩展音量上限至 300%，不增加当前音量；关闭时，高于 100% 的当前音量降至 100%。设置窗口也使用对应名称，支持搜索“声音”“增强”“300”。

| 验证 | 结果 |
| --- | --- |
| 编译 | 最终便携 EXE 编译成功 |
| GUI 实际显示 | Windows 175% 缩放；顶部使用指定蓝色，四个圆角仅作用于蓝色栏 |
| 图标边距 | 最终编译版实际显示，右上角按钮与圆角保留距离 |
| 窗口拉伸 | 实际拖动左上角，窗口尺寸变化并记录一次拉伸，工具栏内容恢复，圆角随宽度更新 |
| 声音增强开启 | 实际点击开关，音量仍为 75%，原生 `volume-max` 从 100 变为 300 |
| 手动增强音量 | 实际拖动滑杆，音量调至 300%，左上角显示百分比提示 |
| 关闭增强 | 实际点击开关，音量及原生上限回到 100% |
| 浮层收起 | 再次点击工具栏音量按钮，面板收起 |
| 模式切换 | 最终编译版通过公开 IPC 完成最大化→全屏→退出全屏→普通窗口→全屏→普通窗口，六次均完成 |
| 模式还原 | 还原后普通窗口尺寸一致，标题栏和底栏内容恢复，蓝色与圆角半径保持一致 |
| 退出 | 独立测试播放器正常退出 |

桌面输入使用 Computer Use，状态观察与模式检查使用测试播放器自己的公开 JSON IPC。配置、视频与观察记录均在工作区 `test-results/appearance-v16` 中，没有写入正在使用的已安装播放器配置。观察记录中的 `features-history.json` 包含声音增强、拖动音量和拉伸过程；`mode-check.json` 包含最终编译版的六次模式切换。

本次只调整顶部外观、圆角面板与增强开关的名称和提示。V15 的播放模式、共享断点、倍速与音量上限逻辑继续沿用；本次进行了与调整直接相关的 GUI 和窗口模式检查，未重复运行 V15 的全部 136 项检查。

便携压缩包为 `mpvnet-modern-V16-win-x64.zip`，内部文件夹仍为 `mpvnet-modern`，程序仍为 `mpvnet.exe`。更新时关闭播放器再替换 EXE，保留已有 `portable_config`。
