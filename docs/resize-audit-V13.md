# V13 窗口拉伸与工具栏验证

日期：2026-10-11。依据用户录屏 `SnowShot_Video_2026-10-11_10-14-06.mp4` 检查窗口拉伸时标题栏重影、底部工具栏闪烁，以及自定义按钮的恢复。

## 实现

原来的拉伸路径在每次尺寸变化时，把八个拖拽区域分别 `BringToFront()`，导致多次父窗口布局。底部 `FlowLayoutPanel` 在尺寸变化时逐个切换按钮的可见状态，也会继续触发布局。

V13 保留标题栏和底栏的占位面板，仅在实际拖动改变尺寸后隐藏其中的内容。视频区域继续随窗口变化，播放状态保持原样。松开鼠标或捕获被取消时，在内容仍隐藏的情况下按最终尺寸排列按钮，再恢复显示。单击边缘但没有改变尺寸时保持内容显示。

- 移除拉伸循环中的八次置顶操作；批量处理窗口和拖拽区域布局。
- 上下工具栏使用各自的缓冲面板，避免影响 mpv 的独立视频渲染窗口。
- 底部自定义按钮改为手动排列，不再依赖流式布局逐个切换可见状态。
- 根据实际按钮宽度、边距和“更多”按钮宽度计算可见前缀，保留用户保存的顺序。全部能放下时不额外预留“更多”空间。
- 新添加的按钮跟随固定工具按钮的实际大小，避免在已经创建的高 DPI 窗口里重复放大；图标模式明确设置为仅图标。
- 退出拖拽后更新进度显示，保存普通窗口尺寸。全屏与最大化的既有显示和恢复规则继续适用。

主要实现文件：`MainForm.ModernWindow.cs`、`MainForm.Modern.cs`、`Modern/ToolbarLayout.cs`、`Modern/BufferedPanels.cs`。
