# FrameFlow 视频播放器

FrameFlow 是基于 mpv.net 源码修改、保留原项目 GNU GPL v2 许可文件与声明的 Windows x64 桌面播放器。来源、版权及各组件许可见随包《开源声明.md》。解压整个文件夹后运行 `FrameFlow.exe`，无需微软商店、MSIX、应用注册或另装 .NET。请保留 EXE 旁的 DLL 和 `portable_config` 文件夹。

当前版本 **V27**，设置窗口右上角显示版本号。可运行文件为 `dist/FrameFlow/FrameFlow.exe`。压缩包为 `FrameFlow-V27-win-x64.zip`，解压后的文件夹固定叫 `FrameFlow`，程序固定叫 `FrameFlow.exe`，文件夹和程序名不加版本号。

## 使用

- **Esc**：默认不退出播放器，也不新增退出全屏行为。已有的关闭右键菜单、音量／倍速／画面调节面板、清空设置搜索、关闭设置或截图预览等作用保留。旧 `input.conf` 中直接绑定 Esc 到 `quit`／`quit-watch-later` 的行在加载时停用；原文件不因此被覆盖。
- **窗口边缘**：普通窗口保留圆角；最大化和全屏时，窗口外框与蓝色标题栏都使用直角并贴边，恢复普通窗口后恢复圆角。
- **从旧版升级**：先退出旧播放器，将旧 `portable_config` 整个文件夹复制到 FrameFlow 目录，保留新旧文件的备份。首次读取会把旧 `mpvnet.conf` 复制为 `frameflow.conf`，原文件保留；如果两者都存在，优先使用 `frameflow.conf`；新包不附此文件的默认模板，以便正常迁移旧配置。`modern-ui.json`、断点、书签和其他配置格式继续兼容。新目录以 FrameFlow 为默认配置目录，并支持 `FRAMEFLOW_HOME`；旧 `MPVNET_HOME` 和已存在的旧非便携配置继续兼容。

- **亮度与夜间护眼**：进入“设置 → 常规 → 画面调节”，或在视频上右键选择“画面调节（亮度 / 夜间护眼）”。亮度滑杆范围为 −100～100，0 表示原始亮度，正值变亮、负值变暗，可单独恢复默认。勾选“夜间护眼（暖色画面）”后，暖色强度可在 0～100% 间调节，每级 5%，默认 35%；关闭时立即恢复原色，保留上次强度。夜间模式默认关闭，调节亮度不会改变暖色强度，开关夜间模式也不会改亮度。设置即时生效并保存，切换视频与重启后沿用；“恢复所有设置默认值”将亮度恢复 0、夜间模式关闭、暖色强度恢复 35%。旧配置若已在 `mpv.conf` 调整亮度，首次升级沿用该值。
- 右键还提供“夜间护眼”直接开关；可在“编辑工具栏 → 画面”添加“画面调节”或“夜间护眼开关”，仍受 16 个槽位限制，默认布局不增加按钮。在“快捷键与鼠标”的常用快捷键列表可自行为这两项分配按键，初始不抢占已有按键。精简调节面板再次点击入口按钮或点击外部即可收起。
- 夜间模式只改变播放器里的视频色彩，不调整显示器或其他软件。使用默认的 GPU 渲染方式，关闭时只移除本功能的着色器，保留用户原有的其他着色器。普通视频截图保持原有截图流程；拉伸时的窗口预览包含亮度与暖色效果。
- 逐帧、前后跳转、点击或拖动进度条、跳到指定时间和书签时，视频左上角显示定位后的实际时间（时:分:秒.毫秒）和百分比，约 3 秒后消失。连续操作更新同一条提示并重新计时；普通播放不反复弹出提示。全屏也能显示。可在“设置 → 快捷键与鼠标 → 画面提示 → 左上角位置提示”选择“不显示”。该项只控制定位提示，音量等操作反馈继续显示。
- 设置每次默认显示“常规”，视频等分类默认收起。只创建当前可见选项的控件，切换分类时按需创建并缓存。V23 原生设置视图使用 32 个控件的缓存预算，超出预算优先释放隐藏视图，当前可见选项保留；释放视图不会丢失已输入的值，重新打开对应项仍显示编辑值，关闭设置释放全部视图。
- 左侧搜索框是全局搜索，与分类导航分开。可以输入“倍速”“断点”“截图”“硬解”，或者技术参数名；多个词用空格隔开，要求同时匹配。右侧每次显示一个完整可编辑的设置项，并标明所属分类与“第几项 / 共几项”。点击“上一个 / 下一个”切换，首尾循环；Enter / F3 下一项，Shift+Enter / Shift+F3 上一项，Ctrl+F 聚焦搜索，清空或 Esc 返回当前分类。无结果时显示提示。
- 普通窗口可从四边和四角自由拉伸，宽高分别调整。边缘使用约 4 个逻辑像素的深色拖拽区域，不绘制系统白框，也不会遮住工具栏和标题栏按钮。松开拖拽或退出时保存普通窗口尺寸及 DPI，下一次打开恢复；全屏、最大化尺寸不会覆盖它。首次运行占显示器可用宽度的 75%、可用高度的 85%。右键菜单顶端的“还原初始窗口大小”会恢复该比例并居中，也可把它加入可编辑工具栏。
- 拖动四边或四角期间，使用完整缓冲的预览层统一绘制当前帧和纯黑背景，上下栏暂时隐藏并保留空间，四个外角仍为圆角。预览显示拖动开始时的画面并随窗口缩放，声音和播放进度继续运行；实际 GPU 视频窗口保留原尺寸，避免反复重建视频和背景区域。松开时应用最后一个待处理尺寸，视频只提交一次新尺寸，确认渲染后恢复蓝色栏、实时画面和按钮。自定义按钮按最终宽度排列一次，多出的按钮进入“更多”。单击边缘但没有实际改变尺寸时保持工具栏显示。工具栏增删、排序、参数和显示文字设置继续沿用。
- 应用图标统一使用 `#0096FF` 蓝色圆底与白色播放三角，包括程序文件、播放器和设置窗口。Windows 文件关联使用同一程序图标；已缓存的快捷方式或视频缩略图角标可能在资源管理器刷新后才显示新颜色。
- 音量、静音、倍速、播放/暂停、字幕、音画同步、缩放、旋转及色彩调整使用与定位相同的左上角提示，显示 3 秒；不再使用中间的音量进度条。连续操作更新提示并重新计时。音量按钮上方展开精简滑杆，可点击或拖动调节，也可静音；再次点击按钮或点击外部关闭。
- 右上角文件夹按钮打开本地视频，也可以把视频拖入窗口。一次打开多个文件会组成播放列表；不会扫描整个电脑或建立影视库。
- 同时播放两个视频时，在“设置 → 常规 → 打开文件时的进程方式”选择“独立进程（multi）”并完成设置。随后从资源管理器或外部命令再次打开文件，会创建独立播放窗口；“单进程（single）”将外部文件转交给已有窗口。在现有播放器内打开文件或点击列表，仍切换该窗口的视频。
- 顶部工具栏只有一行，使用 `#0096FF` 蓝色背景，配白色文件名和图标。普通播放器窗口外框与蓝色栏各自的四个角为小圆角，半径为 10 个逻辑像素并随 DPI 缩放；最大化和全屏时外框贴边显示。V25 蓝色栏使用抗锯齿绘制，曲线边缘平滑过渡到黑色背景；子控件避开两端的圆角区域。窗口四边、四角仍可拉伸，四角的拖拽区域只占深色外缘，外框圆角在拉伸中持续更新。首次打开先绘制标题栏，再加载视频。文件名沿用原来的 10 磅字体，图标按实际按钮尺寸绘制，避免高 DPI 下被遮挡。右上角依次提供视频信息、打开文件、播放列表、置顶 Pin、设置和窗口控制，窗口控制图标较小并单独分组。点击 Pin 切换窗口置顶，开启时按钮显示选中背景。
- “设置 → 快捷键与鼠标”使用“快进倍率”“鼠标操作”“画面提示”三个区域。鼠标区域统一按“操作 → 执行动作”设置，普通滚轮与 Ctrl＋滚轮分别提供调音量、缩放画面、调播放倍率、前进 / 后退、不执行操作或跟随快捷键配置。默认普通滚轮调音量，Ctrl＋滚轮缩放；两项可互换或关闭。Ctrl＋左键拖动独立选择平移画面、不执行操作或跟随快捷键配置；Ctrl＋右键单击与普通左键、右键、中键及侧键同样可以选择常用命令。前进 / 后退使用轻点位移，调倍率使用底部普通倍率的调整步长。“跟随快捷键配置”分别使用 `input.conf` 中对应的按键绑定；高精度滚轮的部分刻度按两种操作分别累计，不执行两遍。Shift / Alt 及横向滚轮仍走原生配置。旧版滚轮与拖动开关会迁移为对应动作。显示定位时间与百分比的开关移到“画面提示”下拉框，与鼠标动作分开。
- 音量面板中的“声音增强”默认关闭，滑杆、选择“调节音量”的滚轮和音量快捷键上限为 100%；开启后上限为 300%，当前音量保持不变，再自行拖动调节，例如原先为 75% 时开启后仍为 75%。关闭增强时，超过 100% 的当前音量和待发送的音量回到 100%。增强与滚轮动作立即生效并保存，增强也可在常规设置中修改。
- 全屏时控制条浮在画面上，离开后约 2.5 秒收起，移到底部再次显示。标题栏移到屏幕顶部时显示；拖动进度条、操作菜单或打开弹窗时保持控制条可用。收起和显示控制条不改变视频区域尺寸。可在“设置 → 常规 → 播放与显示”关闭自动收起；普通窗口和最大化窗口保持控制条显示。
- 默认在视频画面内按住 Ctrl 滚动鼠标滚轮，可围绕鼠标位置放大 / 缩小画面（适配画面的 25%–1600%）；也可把此动作改为普通滚轮或其他功能。按住 Ctrl＋左键拖动查看其他位置，默认 Ctrl＋0、工具栏“还原画面缩放与位置”或右键菜单顶部“还原初始画面大小和位置”恢复缩放和平移；画面复位不会改变播放器窗口尺寸。只调整显示，不修改视频文件；切换到另一个视频会清除本次鼠标操作产生的缩放与平移。可在“快捷键与鼠标”独立关闭拖动画面或修改复位快捷键。
- 设置直接打开统一的中文设置窗口，包含常规、视频、音频、字幕、快捷键与鼠标及底层参数。在“设置 → 快捷键与鼠标”中，视频画面和标题栏可分别选择全屏 / 退出全屏、最大化 / 还原、播放 / 暂停、不执行操作。修改立即生效，退出再打开仍保留；拖动标题栏照常移动窗口。画面双击默认播放 / 暂停，标题栏双击默认最大化 / 还原。“跟随快捷键配置”是另一个可选动作，选择后会使用快捷键文件中设置的双击动作。已手动保存的双击动作会继续保留。
- “快捷键与鼠标”集中提供 26 项常用功能，包含播放 / 暂停、连续快进 / 快退、独立长按快进、逐帧、切换视频、音量与静音、倍速、全屏、置顶、画面复位、截图、打开视频及设置。选中功能后点“录入 / 修改”或双击它即可录入组合键；可清除绑定、恢复原绑定，重复按键会提示冲突。鼠标左键、右键、中键及侧键动作也在这一页选择。改动立即生效并保存到 `modern-ui.json`，普通修改不会重写原有 `input.conf`。
- 主窗口及设置窗口的右键菜单不显示键盘快捷键提示，避免改键后显示旧文字；实际按键以快捷键表和配置为准。轨道序号和章节时间等内容信息继续显示。
- 左右方向键的轻点与长按共用“方向键快进 / 快退倍率”，为绝对倍率，独立于底部播放倍率。左右只改变移动方向。例如设为 6 倍，长按右键按 6 倍播放，长按左键目标为每秒回退 6 秒；底部设为 1.5 倍也不参与相乘。轻点使用另一个“轻点计算时长（毫秒）”栏位：每次位移 = 方向键倍率 × 计算时长 ÷ 1000，界面实时显示换算结果。V25 新配置与恢复默认统一为 6.00 倍、500 毫秒，轻点一次前进 / 后退 3 秒。计算时长不是触发门槛：仍沿用 V21 的 40 ms 计时器及约 180 ms 长按判断，轻点在松开时定位，持续按住进入连续操作。已有自定义倍率与计算时长保留；从 V21 升级时仍一次性迁移原操作速度与轻点幅度，但单项“恢复默认”现在使用 6.00 倍和 500 毫秒。
- 独立长按快进默认使用 Tab，倍率独立设置，默认 3.00 倍，范围 1–16 倍；它与方向键、底部播放速度分别保存。松开前持续按住才能触发，轻点这个独立键不做方向键小步定位；可在常用快捷键表修改或清除绑定。左右方向键和独立长按键松开后恢复原速度与暂停状态；失去焦点、拖动进度或切换视频立即结束。快退通过连续精确定位显示更早画面，实际流畅度受编码和解码能力影响。长按期间进度条、底部时间与左上角时间戳 / 百分比持续更新，全屏底栏保持显示；松开后最终提示再保留约 3 秒。普通左右键固定 5 秒及常用设置 / 默认菜单 30 秒跳转已取消；旧的普通 Up / Down 30 秒默认绑定停用，其他自定义组合键保留。
- 设置底部“恢复所有设置默认值”恢复全部新旧偏好，包含独立快进倍率、方向键倍率、轻点计算时长、键盘 / 鼠标绑定、音量增强、播放模式、工具栏、窗口尺寸及底层配置。恢复前复制配置到 `portable_config/settings-backups/时间戳`，保留每个视频的播放断点、书签及最近文件。V25 全局恢复回到新配置的工厂默认值（方向键 6 倍、500 毫秒；独立快进 3 倍），轻点位移为 3 秒；普通播放恢复 1.00 倍。设置窗口会重新加载默认值，底层需要重启的部分会显示提示。单项恢复只恢复对应项，不影响其他设置。
- 拖动进度、音量和倍率时，滑块立即跟随指针，后台合并频繁的更新；进度松开时提交一次精确定位，尚未完成解码时不会把滑块拉回旧位置。新的定位和新视频会取消旧的拖动目标。
- 底部倍率按钮展开紧凑浮层，只保留倍率输入、滑杆、每次调整和“记住速度”，不带关闭叉和快捷倍率按钮区。再次点击倍率按钮、点击外部或按 Esc 收起。范围为 `0.25–16.00` 倍，支持 `1.34`、`12.34` 这样的两位小数。调整步长可选 `0.01`、`0.05`、`0.10`，工具栏的自定倍率按钮也支持到 16 倍。默认记住退出前的倍率，高倍速重开仍保留。默认变速不变调音频处理的上限同步到 16 倍；手动配置的变速音频滤镜继续使用自己的参数，关闭“不改变音调”时不会强制插入此处理。高倍速的流畅程度取决于解码性能。
- 上一个、下一个视频使用实心三角与竖线图标；上一帧、下一帧使用带边框的空心三角，与切换视频区分。逐帧调用 mpv 原生帧命令，会暂停；回退受视频格式和解码方式影响，长 GOP 视频可能稍慢。
- 视频信息读取当前文件的分辨率、容器标称帧率、编解码器、音频声道和采样率。没有音频或无法读取的字段显示空缺，不编造数据。VFR 视频的标称帧率不代表每一帧都等间隔。
- “打开所在文件夹”在视频信息窗口中，打开资源管理器并选中文件。
- 点击右上角播放列表，在主窗口右侧展开 / 收起；拖动分隔线可调整宽度。双击列表项切换视频，下方可添加、上移、下移、移除；清除按钮保留当前视频并清除其他列表项。拖入右侧列表会追加文件。列表开关和宽度会保存。
- 打开单个本地视频时，自动列出同目录的视频，按文件名自然排序，只扫描当前文件夹，不包含音频、字幕和子目录。保留当前正在播放的文件与进度；一次明确打开多个文件的手动队列不会被覆盖。可在“常规”关闭自动目录列表；点击列表顶部的刷新按钮可重新读取目录。顶部播放模式按钮可选择顺序播放、单个循环、列表循环、随机播放或“播完当前就停”，所选模式会保存。“播完当前就停”在当前视频结束后暂停并保留末帧与完整列表，仍可手动切换视频；切回顺序播放恢复自动进入下一条。
- 工具栏编辑器提供 67 项功能，可按分类筛选或搜索。自定义区域预分配 16 个槽位，默认 6 个按钮占用其中 6 个；固定的播放、切换视频、倍率及右侧控制按钮不占这些槽位。编辑器显示已用数量与剩余数量，满槽后添加按钮禁用，必须先移除一个才能添加。空槽不画线或占位框，只在相邻已有按钮之间绘制细分隔线。支持移除、拖动排序、默认按钮和显示文字；窄窗口中多出的按钮收进“更多”，放大后按原顺序恢复。V16 已保存超过 16 个按钮的配置会保留原按钮，额外按钮可从“更多”访问，减少到 16 个以下后才能添加。添加参数按钮时可自定数值；选中已添加按钮后点“编辑参数”，或双击它，可再次修改。
- 书签保存当前视频的时间点。书签列表里双击跳转；复制时间戳会复制文件路径和时间。
- 点击截图按钮会弹出当前帧预览，可以选“保存到…”自行选择目录和文件名（PNG 或 JPEG），或者选“复制到剪贴板”直接复制图片。关闭预览或取消另存为不会自动保存。含字幕和不含字幕截图共用此流程；默认快捷键 `s` 含字幕，`Shift+s` 不含字幕。画面在内存中截取，不生成默认目录文件。AB 循环按钮依次设置 A、B、取消。
- 光标默认保持可见，方便 UU 等远程控制。需要自动隐藏时，可在“设置”打开“播放时自动隐藏光标”；只在视频区域静止时隐藏，移到按钮上恢复。

## 远程鼠标修复（7.1.2-modern.2）

修复内嵌视频区域未转发鼠标输入的问题，鼠标坐标按视频区域换算。点击窗口时保留第一下点击。按钮在收到有效的按下、抬起消息后处理操作，兼容远程控制中桌面命中判定与实际消息不同步的情况；拖出按钮松开、失去鼠标捕获、禁用和输入校验失败仍会取消操作。进度条松开时使用最终位置，失去捕获后停止拖动。

更新已有便携版时，退出播放器，用新 `FrameFlow.exe` 替换旧文件即可。保留原来的 `portable_config`，继续使用倍率、断点、工具栏和书签设置。新版会自动移除工具栏中的旧插件按钮；旧插件文件不会自动删除或运行。完整包需整个解压。

## 右侧播放列表与工具栏（7.1.2-modern.3）

已移除自定义插件管理窗口、安装入口、独立插件运行器及 Jint 依赖。常用功能现在作为内置按钮提供。播放列表在主窗口右侧，不再使用弹窗。

| 分类 | 可添加功能 |
| --- | --- |
| 播放与跳转 | 上一帧、下一帧、自定秒数前后跳转、开头、指定时间、章节、单视频循环、列表循环、停止 |
| 倍速 | 自定固定倍率、按设定步长增加 / 降低、恢复 1.00 倍 |
| 书签与截图 | 添加书签、书签列表、复制时间戳、含 / 不含字幕截图、AB 循环、取消 AB 循环 |
| 字幕 | 显示开关、切换字幕、加载文件、自定提前 / 延后秒数、同步还原、大小、位置 |
| 音频 | 切换音轨、静音、自定音量增减、自定声音提前 / 延后、音画同步还原 |
| 画面 | 自定缩放、上下左右平移、旋转、原始 / 16:9 / 4:3 比例、亮度、对比度、饱和度、还原 |

字幕、音轨、章节功能需要文件有相应轨道或章节；没有内容时不会生成新轨道。截图预览以视频画面的分辨率生成，不包含播放器按钮；当前保存和复制输出为 8 位图片。底层截图目录、命名模板及编码参数供自定义 mpv 原生截图命令使用，工具栏和默认截图快捷键由弹窗选择位置与格式。循环、置顶、静音等开关按钮会用强调色显示当前状态。

## 设置位置

普通打开和 MarkText 笔记跳转共用 `modern-ui.json` 的 `Positions`，每个视频只有一份已保存进度。手动看到 20 分钟，再点击笔记的 7 分 41 秒并继续播放，普通重开从最近实际播放的位置继续。Markdown 时间戳仍是固定锚点，点击它时优先跳转，不会被播放进度修改。

外部程序通过 `--start`、`loadfile` 的 `start` 选项或加载后的 IPC `seek` 指定时间时，指定的时间优先；显式指定 `0` 也有效。启动时 `--resume-playback=no` 跳过自动恢复，插件后续的精确定位会更新共用进度；关闭保存请使用界面中的“记住每个视频的播放位置”。在插件创建的窗口中重新手动打开文件，使用共用断点规则。断点在开始播放之前作为本文件的起始位置处理，不再在 `file-loaded` 后补发跳转。

V12 在初始化时关闭 mpv 原生 `watch_later` 自动恢复与退出保存。旧文件保留，仅在该视频没有 `Positions` 记录时导入；有共用记录时，包括已保存的零秒，都不会被旧原生记录覆盖。多个窗口各自播放，画面不会同步跳转；最近打开、跳转或从暂停继续播放的窗口负责更新该视频的断点。旧窗口的定时保存和退出保存不能覆盖新窗口的进度。不同视频的记录合并保存，设置保存也不会把启动时的旧断点整份写回。

单实例手动打开只转发给同一 EXE 路径、同一配置目录的播放器，并校验进程身份。转发保留起始位置、播放状态等本次文件选项；连续打开仍按替换处理，不会因间隔小于一秒自动变成追加队列。只有明确追加的操作才会排队。

V20 停用内核的 `autocreate-playlist`，统一由前端把同目录视频追加到列表，避免内核重建当前条目时丢失 `loadfile` 的 `start` 参数。明确的新起始时间会取消旧的长按快退与进度拖动目标，目录列表本身不重载当前视频。

所有播放器设置保存在同目录的 `portable_config`，包括 `modern-ui.json` 中的倍率、断点、工具栏和书签。播放列表的展开状态、宽度、两个位置的双击动作，以及全屏控制条和 Ctrl 鼠标操作的开关也保存在 `modern-ui.json`。旧配置会自动沿用原有双击动作，并启用新增的两个开关；无效双击选项会单独恢复默认，不影响其他设置。

## 分隔线与窗口

普通窗口、最大化、全屏下拖动播放列表左边的分隔线，只调整列表宽度。之前内嵌播放画面的尺寸变化会被误当作主窗口还原，现在窗口状态由主窗口管理。退出全屏恢复进入前的普通窗口或最大化状态，保留普通窗口的尺寸和位置。

松开分隔线时立即保存列表宽度，关闭列表再打开、退出播放器再打开都会恢复。宽度以 96 DPI 的逻辑像素保存；可设定 210–600，实际可用上限还受窗口宽度限制，列表最多占中间区域的 40%，并给视频留出空间。窗口临时缩小时只收窄显示，保留设定宽度；放大后恢复。三个窗口模式共用同一份宽度设置。

## 外部操作

默认提供 Windows 命名管道 `\\.\pipe\mpvnet-modern`。协议为每行一个 UTF-8 JSON，沿用 mpv 的命令、属性读取、属性订阅和事件机制。没有 HTTP 服务，也没有向公网监听。

`user-data/modern/resume` 提供共用断点诊断：`policy`、进程 `pid`、视频 `file`、配置位置 `config`、显式起点 `requestedStart`、恢复来源 `source`、采用的断点 `restored`、加载状态 `loaded` 和最后保存是否被接受的 `saveAccepted`。`ResumeOwners` 只保存窗口的写入标识，不保存另一套时间。该标识用于拒绝旧窗口回写较新的断点。

```json
{"command":["set_property","speed",1.34],"request_id":1}
{"command":["get_property","time-pos"],"request_id":2}
{"command":["observe_property",1,"time-pos"],"request_id":3}
```

可以用 `scripts/ipc-client.py` 操作。通过 `modern-tool` 调用与工具栏相同的内置功能，例如：

```json
{"command":["script-message-to","mpvnet","modern-tool","sub-later","0.17"],"request_id":4}
{"command":["script-message-to","mpvnet","modern-tool","playlist"],"request_id":5}
{"command":["get_property","user-data/modern/tools"],"request_id":6}
```

`user-data/modern/tools` 返回全部按钮 ID、分类、默认值和可选参数；`user-data/modern/playlist` 返回右侧列表的开关状态、当前项、数量及文件；`user-data/modern/state` 返回播放快照。这些扩展属性值是 JSON 字符串，可通过 `observe_property` 订阅。`script-message-to` 的成功回复表示命令已分发；操作结果应通过状态或对应 mpv 属性确认。

`user-data/modern/navigation` 返回提示的 `visible`、`kind`（`navigation` 定位 / `operation` 操作）、`action`、`time`、含毫秒的 `timestamp`、`percent`、`text` 和 `durationSeconds`；可以订阅提示显示、更新、隐藏。`user-data/modern/volume` 提供音量滑条的 `visible`、`volume`、`muted` 及物理像素 `bounds`。音量与静音仍通过 mpv 原生属性控制。

`user-data/modern/held-navigation` 提供方向、状态、V21 触发门槛、当前操作倍率、普通播放的原倍率 / 暂停状态、独立倍率、方向键倍率、轻点毫秒数和换算秒数。`user-data/modern/mouse` 提供 `wheel`、`ctrlWheel`、兼容字段 `ctrlDrag` 及 `ctrlDragAction`，拖动动作 ID 为 `pan` / `none` / `input-conf`，滚轮动作 ID 为 `volume` / `zoom` / `speed` / `seek` / `none` / `input-conf`。`user-data/modern/window.controls` 的 `previewVisible` / `previewHasFrame`、`previewCaptures` / `previewFailures` / `previewRevealTimeouts`、`frozenVideoWidth` / `frozenVideoHeight` 与 `videoCommits` 可核对拉伸预览、冻结尺寸和松开后的单次提交。

`user-data/modern/settings` 返回设置窗口的显示/渲染状态、搜索词、当前保留和总控件数、耗时及当前可见选项。`nativeControlCacheLimit` 是原生控件缓存预算，`createdNativeControls` 是本次设置窗口累计创建数量，后者不代表当前占用。还提供当前 `category`、分类展开状态 `categories`、搜索 `results`，其中包括 `count`、从 1 起算的 `index`、当前候选 `current` 及 `matches`。`["script-message-to","mpvnet","show-conf-editor","解复用:"]` 可打开或切换到设置分类；也可使用参数名或中文搜索词。已打开的设置窗口会复用；不传搜索词时回到常规并收起分类。

播放模式可用 `modern-playlist` 控制；`sequence` 为顺序播放，`single-loop` 为单个循环，`list-loop` 为列表循环，`random` 为随机播放，`stop-current` 为播完当前就停。`refresh-folder` 重新列出当前目录的视频。列表快照增加 `directory`、`autoFolder`、`mode` 和 `modeTitle`。自动扫描只处理当前目录的本地视频；手动打开的多文件队列保留原顺序。音量快照 `user-data/modern/volume` 包含浮层可见状态、当前音量、上限、扩展和滚轮开关；倍率浮层可见状态可读取 `user-data/modern/speed`。

```json
{"command":["script-message-to","mpvnet","modern-playlist","mode","single-loop"],"request_id":9}
{"command":["script-message-to","mpvnet","modern-playlist","refresh-folder"],"request_id":10}
{"command":["script-message-to","mpvnet","modern-tool","window-reset"],"request_id":11}
```

主窗口操作使用 `modern-window`，支持 `maximize`、`restore`、`minimize`、`fullscreen`、`exit-fullscreen`。`restore` 还原为普通窗口；`exit-fullscreen` 返回进入全屏前的窗口模式。原生 `window-maximized` / `window-minimized` 反映内嵌 mpv 画面窗口，不能用来判断或改变主窗口。`fullscreen` 属性仍可读写，也可继续用原来的全屏快捷键。

`user-data/modern/window` 增加 `resizing`、`controls.contentHiddenForResize` 与工具栏内容的实际可见状态；`toolbar` 返回按钮数量、当前可见前缀、溢出状态、实际尺寸、排列次数和按保存顺序列出的按钮矩形。`controls.headerColor`、`headerRenderingSuspended`、`headerRegionUpdates` 与 `resizePixelDiscards` 可核对拉伸时的深色占位、圆角暂停和旧像素丢弃。可通过属性订阅确认拖拽开始、松开后的恢复以及“更多”中收纳的按钮。

```json
{"command":["script-message-to","mpvnet","modern-window","maximize"],"request_id":7}
{"command":["get_property","user-data/modern/window"],"request_id":8}
```

`user-data/modern/window` 提供主窗口 `mode`（`normal` / `maximized` / `fullscreen` / `minimized`）、DPI、当前边界、普通窗口边界、屏幕边界、显示器可用区域 `workArea`、默认居中边界 `initialBounds` 和播放画面尺寸；边界和画面尺寸使用物理像素，可订阅变化。`controls` 提供控制条与标题栏的显示状态、相对主窗口的物理像素边界、全屏自动收起开关及延迟。播放列表快照还提供 `width`（当前逻辑宽度）、`widthPixels`（当前物理宽度）和 `preferredWidth`（保存的逻辑宽度）。

自定管道名称可在 `mpv.conf` 设置 `input-ipc-server`，程序会保留配置，便于多个独立配置并存。

## 从源码构建

运行 `scripts/bootstrap.ps1` 自动准备官方 .NET 10 SDK 和 mpv.net v7.1.2.0 的官方 x64 播放组件到 `.tools`，再运行 `scripts/build-portable.ps1` 生成 `dist/FrameFlow`，运行 `scripts/package.py` 生成带公开版本号的便携包、对应源码包和校验文件。构建脚本不会注册应用或安装文件关联。

公开版本在 `MpvNet.Windows.csproj` 的 `ModernVersion` 中统一管理，界面、EXE 元数据和压缩包名共用此值。发布下一版前运行 `python scripts/version.py --next`，会自动跳过所有含数字 4 的版本，例如 V3 → V5、V13 → V15、V39 → V50；普通编译与重新打包不会增加版本。运行 `python scripts/version.py` 查看当前版本。
