# V17 外观、圆角与工具栏容量验证

日期：2026-10-11。版本 `7.1.2-modern.17`，EXE 文件版本 `7.1.2.1017`。

本版落实已确认的预览：顶部背景 `#0096FF`、白色文字与图标，普通窗口外框与蓝色栏各自四个圆角，半径为 10 个逻辑像素。文件名保留 10 磅 Microsoft YaHei UI；图标改按实际控件尺寸绘制并留出安全边距，功能图标目标为 24 像素，窗口控制目标为 18 像素，均按实际按钮高度缩放。窗口控制前有分组线。底部相邻已放置按钮之间绘制细分隔线，不在空槽或空白区域画线。

切换视频的图标为实心三角加竖线，逐帧图标为带边框的空心单步三角。自定义区域有 16 个槽位，固定的播放、切换视频、倍率与右侧按钮不占槽位。默认六个按钮后还有十个空槽；添加第十六个后禁用添加，移除后恢复。为保留旧配置，超过 16 个的旧按钮继续保留，但额外项只在“更多”中访问，不能继续添加。

普通窗口使用裁剪区域保证四个圆角；开始拉伸时只清除一次外框裁剪，松开后恢复一次，继续沿用拖动期间隐藏上下工具栏内容的处理。四角拖拽区域为 L 形，仅占深色边缘，避免矩形角块盖住蓝色栏。最大化与全屏清除外框圆角，还原普通窗口后恢复。

| 验证 | 结果 |
| --- | --- |
| Release 便携编译 | 成功，保留项目已有的编译警告 |
| 配置、断点与布局测试 | 103 项通过，包含新增的槽位上限、拒绝第十七项、移除后替换、保存重开、旧按钮保留及 1000 种宽度下的有序布局 |
| 实际 GUI | Windows 175% 缩放；蓝色正确，四角圆润，右上角图标完整显示，三个窗口控制较小，文件名字体保留 |
| 分隔线与图标 | 实际默认六按钮及十五、十六按钮布局；相邻已有按钮有细分隔，空白区域无占位线，逐帧与切换视频图标不同 |
| 四边、四角拉伸 | 八次实际鼠标拖动均改变对应边界，普通窗口从 1450×880 逐步缩为 1240×670，松开后工具栏可用且圆角恢复 |
| 窗口模式 | 最大化→全屏→退出全屏→普通窗口→全屏→普通窗口六次检查通过，普通窗口尺寸保留，模式与外框圆角状态一致 |
| 满槽添加 | GUI 从 15 添加到 16，显示剩余 0；添加按钮禁用，状态 `canAdd=false` |
| 移除后恢复 | GUI 移除所选按钮后剩余 1、`canAdd=true`；再次添加恢复 16 |
| 窄窗口 | 满槽窗口实际缩到约 820 像素宽，7 个自定义按钮显示，其余 9 个出现在“更多”菜单，原 16 个槽位仍保留 |
| 隔离测试退出 | 两次测试播放器均通过自己的 IPC 正常退出 |

桌面输入使用 Computer Use；状态与模式检查使用独立测试播放器自己的公开 JSON IPC。测试记录位于 `test-results/controls-v17`：`settings.log`、`resize-history.json`、`mode-check.json`、`filled-slots-state.json`、`freed-slot-state.json`、`narrow-slots-state.json` 与 `slot-history.json`。没有修改或关闭已安装播放器，也没有写入其配置。

本次直接修改的是工具栏外观、圆角、图标和容量限制。共享断点等已有设置测试仍通过；没有重复运行此前版本的所有插件跳转、声音和倍速端到端场景。GUI 在一套 175% 缩放桌面上检查，其他 DPI 的工具栏宽度预算由模型测试覆盖。

便携包 `mpvnet-modern-V17-win-x64.zip` 内部仍为 `mpvnet-modern/mpvnet.exe`，只含出厂配置，不包含本次测试的断点和工具栏记录。更新时关闭播放器替换程序文件，并保留自己的 `portable_config`。
