# V15 控件与播放模式验证

日期：2026-10-11。发布版本为 `7.1.2-modern.15`。按用户要求跳过含数字 4 的版本号；便携压缩包为 `mpvnet-modern-V15-win-x64.zip`，内部文件夹仍为 `mpvnet-modern`，入口仍为 `mpvnet.exe`。

## 本次调整

- 顶部单行标题栏改为浅蓝色 `#D2E8FA`，文件名和按钮使用深色；新增 Pin 置顶按钮，选中状态跟随原生 `ontop` 属性。
- “滚轮调节音量”独立保存，关闭后普通滚轮不改变音量。Ctrl 缩放先于普通滚轮音量处理，带修饰键的滚轮继续使用既有输入配置。
- 音量默认上限 100%；开启“扩展至 300%”后，浮层滑杆和原生音量上限均为 300%。关闭扩展时，高于 100% 的当前音量立即降至 100%。音量提示沿用左上角 3 秒提示。
- 音量和倍速改为无标题栏、无关闭叉的浮层，再次点击对应工具栏按钮收起。点击外部或按 Esc 也可收起。
- 倍速面板去掉全部快捷倍率按钮，内容尺寸为 280×218 逻辑像素，保留数值输入、滑杆、每次调整步长、速度记忆和范围说明；支持 0.25–16.00 倍。
- 播放模式增加“播完当前就停”。保留完整列表，在当前视频末尾暂停并保留画面，不自动进入下一项；手动“下一个视频”仍然可用。切回顺序播放恢复自动续播。
- 右键菜单顶部新增“还原初始画面大小和位置”，调用既有画面缩放与平移复位，同 Ctrl＋0。原来的“还原初始窗口大小”继续独立使用。

“播完当前就停”使用 `keep-open=always` 与 `keep-open-pause=yes`，退出此模式恢复之前的常规选项。原生行为依据 [mpv 的 keep-open 说明](https://mpv.io/manual/stable/#options-keep-open)。音量上限通过 [volume-max](https://mpv.io/manual/stable/#options-volume-max) 设置。

## 更新方式

从 V13 更新可先退出播放器，再替换 `mpvnet.exe` 并保留已有 `portable_config`；已有断点、书签、播放速度和工具栏配置继续使用原记录。完整便携包与对应源码包同时提供，沿用 GPL v2 许可。
