# V21 长按导航与进度反馈检查

检查日期：2026-10-12。Windows x64，构建版本 V21（7.1.2.1021）。

本次针对长按左右键后进度条与左上角时间没有变化，以及移除前进 / 后退 30 秒的要求。

## 原因与修复

修复前，视频宿主的 `PreProcessMessage` 会消耗普通 Right 按键，把方向键当成 WinForms 控件焦点导航。隔离播放器停在 60.023 秒时，新增的窗口输入测试在这一断言失败，`held` 仍为 0。旧测试直接调用 mpv 的 `keydown` / `keyup`，绕过了 WinForms 预处理，未覆盖这条实际输入路径。

视频宿主和主窗口现在把方向键标为输入键，让按下、重复和抬起消息进入原有 mpv 转发流程。普通工具栏点击完成后把按键焦点交回视频；编辑弹层、菜单和对话框保留自己的焦点。

原来长按开始时只显示一次“连续快进 / 快退”，正文没有时间戳或百分比，三秒后会过期。临时速度、暂停变化还可能把这条提示覆盖。现在长按每次刷新时把同一已解码时间用于进度条、底部时钟和左上角时间戳 / 百分比；持续刷新提示期限，松开后最终提示再保留约三秒。快退松开后的最后一次精确定位完成后显示最终时间。临时速度 / 暂停通知及其迟到事件不覆盖定位提示，临时倍率不写入保存设置。

全屏自动隐藏底栏会在长按期间保持显示，松开后恢复原自动隐藏规则。逐帧按钮默认仍各一个，自定义区域默认仍为六个按钮。

## 移除 30 秒跳转

常用快捷键表移除“前进 30 秒”和“后退 30 秒”，由 25 项变为 23 项。默认导航菜单移除对应条目，普通 Up / Down 明确不执行播放动作。仅当旧的普通上下键绑定恰好为 `seek 30` / `seek -30` 时迁移为停用；其他自定义绑定和修饰键保留，不重写用户的 `input.conf`。

## 验证

窗口集成测试使用本测试进程视频控件的标准消息预处理及 `WndProc`，再由应用转发给实际 libmpv / GPU 子窗口，不向其他程序注入输入。测试记录包括底部滑块位置、时钟文本、左上角时间与百分比、提交的 ASS 文本和原生播放位置。

覆盖：

- 视频宿主及主窗口的方向键不再被预处理消耗；点击播放按钮后输入焦点正确，倍率 / 音量弹层可正常开关。
- 连续向前及向后播放时，滑块、时钟和实际提交的顶部提示同步更新；重复按下不重置长按起点。
- 长按超过三秒仍显示实时提示，全屏底栏保持可见；松开后的提示接近三秒时仍显示，随后过期。
- 关闭定位提示后长按不再显示时间提示；长按期间的独立音量提示仍按三秒期限收起。
- 松开恢复原速度和暂停，短按作小幅定位，失去焦点结束操作，临时速度不保存。
- 常用设置及默认菜单不再提供 30 秒跳转；旧默认上下键绑定停用。
- 拖动合并、单次最终精确定位、音量增强上限、自定义快捷键冲突、设置搜索及新文件显式时间戳回归。

本地结果保存在 `test-results/controls-v21/live/observations.json`、`test-results/controls-v21-live.log` 和 `test-results/settings-v21.log`。`held-forward-osd.png` 是实际 GPU 输出截图，视觉检查可见左上角连续快进时间戳及百分比。测试视频帧和隔离配置不进入发行包。
